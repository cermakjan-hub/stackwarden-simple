# Security

What the plugin runs, reads, writes, connects to and sends, each with the file that does it, is in the README: [What it does on your computer](README.md#what-it-does-on-your-computer).

To report a security problem, open an issue at https://github.com/cermakjan-hub/stackwarden-simple/issues that says you have one, without its details, and we'll arrange a private way to hear them.
